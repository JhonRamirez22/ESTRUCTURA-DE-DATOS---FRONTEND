# Public Sans

Fuente variable de Google Fonts, alojada localmente para evitar solicitudes
de red durante el build y la carga tipográfica.

Origen: https://github.com/google/fonts/tree/main/ofl/publicsans
Archivo: PublicSans[wght].ttf, convertido a WOFF2 con fontTools.
